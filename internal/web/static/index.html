Setup code

The installer printed a link that contains it. On the server it is also in the file .setup-code of the stack folder, e.g. sudo cat /opt/stackwire/.setup-code.

Your login

One login for this page and every app stackwire installs.

We made one up for you; type your own if you like. 12 to 64 characters: letters, digits and . _ ~ ! @ + = , : ^ * -. Save it in your password manager.
